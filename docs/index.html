Output stays with the command that made it.

Command blocks

Each command gets a header with its exit status and run time. Copy, rerun, or jump between blocks.

A real editor for input

Syntax-highlighted, multi-line, with completion. Programs that need raw keys, like vim, get the whole terminal.

Ask AI for a command

Start a line with # and describe what you want. Kiln drafts the command for you. It needs your own API key in settings.

Works with agents

Run Claude Code, Codex or Gemini and Kiln hides its own input so they have the full window.

Search history

Fuzzy-find any past command, or start from a built-in workflow like undoing the last commit.

Split panes and themes

Split any direction. Five dark themes, adjustable font size.
